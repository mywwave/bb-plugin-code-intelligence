# Support

Use GitHub Discussions for how-to questions, ideas, and general usage help.
If Discussions are unavailable, open an issue using the repository's question
or feature route and include the BB version, plugin version, operating system,
and relevant non-sensitive output.

Do not use public issues or Discussions for vulnerabilities, credentials,
private repository paths, or user data. Read [SECURITY.md](SECURITY.md) for a
private vulnerability-reporting path.
