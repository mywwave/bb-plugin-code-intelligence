# Governance

## Maintainer

Michael Yong is the initial maintainer and has merge and release authority for
Code Intelligence. The maintainer is responsible for applying the contribution,
security, and conduct policies consistently.

## Decisions and merges

Contributors may propose changes through issues and pull requests. A pull
request requires a successful local `npm run check`, a focused review, and
maintainer approval before merge. The initial maintainer makes the final
decision when consensus is not reached and explains a significant decision in
the relevant issue or pull request.

## Adding or removing maintainers

The initial maintainer may add a contributor who has demonstrated sustained,
constructive work and agrees to these policies. Maintainers may be removed for
extended inactivity, a conflict of interest, or repeated policy violations.
The initial maintainer records the change in a repository issue or release
note when it affects contributor expectations.

## Policy changes

Changes to this document, the Code of Conduct, or the security policy are made
through a pull request and announced in its description. Urgent security or
conduct changes may be made directly and documented immediately afterward.
